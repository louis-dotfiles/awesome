# Awesome window manager configuration README

Right. I will keep this repo just in case I decide to go back to Awesome at some
point. But for real.

Good things:
- Lua scripting is nice.
- It is functional. You can do a lot of stuff on your own.

Bad things:
- The example rc.lua configuration file should have been split into at least 6
  different files to begin with. it was a chore to go through it the first few
  days.
- Little to no typing support of the Lua libraries / API. Working with them is
  **very**, and I mean **VERY** hard.
- Generally speaking, the API is weird and difficult to understand.
- The documentation is average at best. Lots of things are explained in
  "explanantion" articles but not referenced by any other page. e.g. The button
  numbers, no mention of what they are in the function references, but there is
  an article on the website, you "just" have to dig to find the information.


So, my general feeling about Awesome:
- Yes, you can probably achieve any look you can imagine with Awesome. I don't
  think there is animation support but that was not a deal breaker for me.
- It's a pain in the ass to work with. The sparse documentation and lack of type
  support made my life miserable. I am not willing to invest any more time in
  it, I would rather start from scratch with a different window managment
  solution. Event if it doesn't have Lua scripting.


## Requirements

Install the following packages:
- awesome
- vicious
